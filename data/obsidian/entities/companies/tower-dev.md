# Tower.dev

**One-line:** Platform helping data engineers turn AI-generated code into reliable production systems.

## Overview

Tower.dev addresses the "last mile" problem in AI data engineering: AI code generation tools (Copilot, Cursor, etc.) can write data pipeline code quickly, but getting that code into reliable production systems remains brittle and manual. Tower builds the infrastructure layer that validates, deploys, and operates AI-generated data pipelines at production quality.

This is a bet on a second-order AI infrastructure need — the problems that emerge *after* AI code generation becomes ubiquitous. The founders bring direct credibility: both were engineers at Snowflake, one of the defining data infrastructure companies of the last decade.

## Founders

- **Serhii Sokolenko** — CEO. Ex-Snowflake engineer. Saw the AI/data pipeline gap from inside the industry.
- **Brad Heller** — CTO. Ex-Snowflake engineer. Co-founder with Sokolenko.

## Investment Thesis (from Roosh's perspective)

- Domain expertise: ex-Snowflake founders understand data infrastructure deeply
- Second-order AI play: the more AI generates code, the larger the need for reliable deployment infrastructure
- "Building block for the future AI ecosystem" — potential to become foundational infrastructure as AI data pipelines proliferate
- Solving a real pain point that exists today, not a speculative future need
